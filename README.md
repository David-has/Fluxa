# Fluxa – Personal Finance Dashboard

A modern landing page for **Fluxa**, a fictional personal finance management platform designed to help users understand their spending habits, track savings, and manage their budgets.

The project features a clean interface, elegant typography, interactive dashboard elements, and a dark/light theme.

## Overview

Fluxa is a conceptual fintech website focused on making personal finance easier to understand through visual data, budgeting tools, and savings insights.

The design combines a modern financial dashboard aesthetic with smooth animations and responsive layouts.

## Features

- **Dark & Light Mode** – Switch between two visual themes.
- **Interactive Dashboard** – Displays a sample balance, transactions, and financial insights.
- **Financial Charts** – Visual representation of spending over different periods.
- **Savings Calculator** – Estimates potential savings using monthly contributions and annual returns.
- **Budget Management UI** – Visual budget categories and spending alerts.
- **Savings Goals** – Track progress toward financial goals.
- **Subscription Management** – Interactive subscription controls.
- **Pricing Plans** – Free, Plus, and Family subscription options.
- **FAQ Section** – Expandable frequently asked questions.
- **Responsive Design** – Designed for desktop, tablet, and mobile devices.
- **Animated UI Elements** – Visual effects, transitions, and interactive components.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- SVG Graphics
- HTML Canvas

## Getting Started

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in your code editor.

3. Make sure `style.css` and `script.js` are located alongside `index.html`.

4. Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

This project was created to practice and improve front-end development skills, focusing on modern UI/UX design, responsive layouts, interactive components, data visualization, and JavaScript functionality.
